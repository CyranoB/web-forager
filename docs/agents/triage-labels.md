# Triage labels

Map canonical triage roles to these GitHub labels:

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

Use this mapping when a skill asks for a triage role, including the AFK-ready label.
Category labels such as `bug` and `enhancement` are separate from triage status.
