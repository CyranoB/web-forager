## Claude Code

- Keep progress updates brief and report only material findings or changes in
  direction.
- Complete the requested scope without silently expanding it; ask only when
  materially different interpretations would produce different work.
- Delegate only substantial, independent work that benefits from parallel
  execution. Perform routine implementation and validation directly.
- Lead the final response with the outcome, followed by essential evidence,
  caveats, and next steps.

## Agent skills

### Issue tracker

Track issues and specs in the public `CyranoB/web-forager` GitHub repository.
Before issue operations, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before assigning a triage status, read
`docs/agents/triage-labels.md`.

### Domain docs

Use a single root context and root ADR directory. Before exploring the codebase,
read `docs/agents/domain.md`.
